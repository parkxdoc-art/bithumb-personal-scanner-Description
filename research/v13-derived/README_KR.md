# 빗썸 V13 기반 독립 스캐너 V1.0

## 실행 (PC 또는 Pydroid 3)
- Python 3.10 이상, 표준 라이브러리만 사용합니다. 별도 pip 설치 불필요.
- `v13_derived_scanner_V1_0.py`를 실행하고, 같은 기기 브라우저에서 `http://127.0.0.1:8080`을 엽니다.
- 포트 충돌 시 `python v13_derived_scanner_V1_0.py --port 8081`로 실행합니다.
- Render에 별도 서비스로 배포하려면 Python runtime, start command `python v13_derived_scanner_V1_0.py --host 0.0.0.0`, health check `/health`를 사용합니다. requirements 파일은 비워도 됩니다. 이 배포는 아직 수행하지 않았습니다.

## 원본에서 가져온 전략
- 15분 박스: 16봉 박스(ATR 1.5~6배, 상단 2회 접촉), 거래량 2배, 양봉 몸통 60%, EMA96 위 상승, ATR 2배 내 돌파. 6봉 안에 상단+0.3% 이내 눌림 후 상단 위 양봉. 종가 -0.2% 미만 실패. 눌림봉 저가/상단 중 낮은 값 - ATR 0.5배 손절, 위험 4% 이하, 목표 거리 1% 이상. 1.5R 절반 청산, 나머지 직전 저가 기반 상승 전용 추적선, 8봉 시간청산(목표 미도달), 총 48봉 한도.
- 1시간 추세: EMA200, 직전 48봉 고점, 거래량 1.5배. 4시간 추세: EMA50, 직전 20봉 고점. 공통: 고점 돌파 즉시 / 돌파 후 8봉 이내 ATR 0.5배 근처 눌림 후 반등 / RSI 32 이하 및 ATR 3배 조정 후 반등. ATR 3배 추적 손절.
- BTC 빠른/느린 EMA, 선택 종목의 EMA 위 비율(60%/40%), BTC 30일 고점 낙폭(-10%/-20%) 및 6봉 상태 유지. 7일 수익률 상대강도 순위 사용. 전체 시장 폭이 아닌 수집 대상 종목 내 시장 폭입니다.
- 박스 전략에도 시장 게이트를 적용하고 EMA 상승을 추가한 독자적 변형입니다. 강세 상위 50%, 중립 상위 30% (즉시 돌파 보류), 약세/판단불가 신규 진입 보류. 원본 약세장 절반 투입 대신 미거래. 3종목 등 작은 표본에서는 30% 조건상 후보가 없을 수 있습니다.

## 보강/차이점
- 주문·계정·API 키 없음. 현재 KRW 거래대금 5억 이상 상위 5/10/20종목 또는 고정 3~20종목. 스테이블 명시 목록 제외, 고정 종목도 신호 시점 24시간 거래대금 5억 조건 적용. 신규상장 제외 기능은 따로 구현하지 않았고 최소 지표 이력이 부족하면 신호 차단합니다.
- KST 기준 페이지 조회, 실제 완료봉 검사, 누락 구간 검증, 40일 준비 기간. API 418/429 발생 시 5분간 요청 중단. 최초 실행은 다량의 분봉 조회로 느릴 수 있음.
- 추세 초기 위험 6% 이하(원본 15%보다 축소); 추세 24봉 보유 한도(1시간봉 24시간/4시간봉 4일), 부분 익절은 박스 전략에만 적용. 박스+추세 손절 폭은 단타 실전 권장값이 아닌 연구 제한입니다.
- 신호가 확정된 다음 봉의 시가 진입. 같은 봉에서 손절/목표가 동시 도달 시 손절 우선. 추적선 상승은 다음 봉부터 반영. 편도 0.25%, 매수 매도 금액별 반영, 슬리피지 0 가정. 실제 호가/체결과 다름.
- 전략별/일자별 최대 네 거래, 코인별 전략 3시간 쿨다운 및 동일 코인 중복 보유 방지. 전략 사이 결과는 독립 비교이며 합산 계좌 성과가 아닙니다.
- 진입 카드의 가격/손절은 완료봉 종가 기준 참고값으로 다음 봉 실제 시가와 달라질 수 있습니다. 미완결 검증 구간(미래 관측 부족·누락 포함)은 제외 집계하며, 이로 인해 표본 편향이 생길 수 있습니다.
- 백테스트는 현재 선정한 종목의 과거 검증으로 전체 시장의 역사적 거래대금 순위를 재현하지 않습니다. 6일/13일은 신호 관찰 기간이며 40일은 지표용 준비 기간입니다. 보유 구간을 모두 관측하지 못한 신호는 제외합니다. 원본의 신호 장기 저장, 보유 코인 관리, 자동 갱신, 상세 학습/검증 분석은 이번 초기판에서 제외했습니다.
- 결과와 진단 CSV, 날짜별 무거래 0건 표시. 서버 재시작 시 결과는 사라집니다. 공유 웹 배포에서는 실행/결과가 공용 상태이므로 개인 비밀정보를 입력하면 안 됩니다.

## 검증 범위
`python test_v13_derived_V1_0.py` 20개 오프라인 테스트. 로컬 HTTP 서버의 화면 응답, CSV 응답 및 가상 데이터 스캔/백테스트 엔진 테스트 성공. 브라우저 자동 화면 테스트는 실행 환경의 접근 제한으로 완료하지 못했습니다. 실제 빗썸 시장 성과, 실제 API 접속 및 Render 배포는 아직 검증되지 않았습니다. 투자 수익 보장 없음.

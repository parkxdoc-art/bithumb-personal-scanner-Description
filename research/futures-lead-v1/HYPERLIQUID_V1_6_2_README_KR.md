# V1.6.2 대용량 압축 거래 기록 대응

- 주소: https://bithumb-futures-lead-v1.onrender.com/traders/offline
- 트레이더 연구 화면에서 CSV/CSV.GZ 파일을 브라우저의 스트림으로 분할 처리합니다.
- 압축 해제된 모든 텍스트를 메모리에 쌓지 않고 선택한 코인 기록만 분석에 보관합니다.
- 압축파일 80MB, 압축 해제 데이터 512MB, 선택 코인 200,000행까지의 안전 제한이 있습니다.
- JSON/JSON.GZ는 여전히 64MB 제한을 받습니다.
- 원본 진입·청산과 비용 정보를 모두 확인할 수 있는 경우에만 수익을 추정합니다.
- 실제 제3자 CSV 구조의 호환성은 파일을 받아 검증하기 전까지 확정할 수 없습니다.
- 성능 테스트: 86.4MB로 압축 해제되는 가상 파일 102,000행 중 선택 코인 204행, 완결 거래 102건 복원 확인.
- 지갑 연결·거래소 API·자동 주문 없음. 파일은 Render에 전송하지 않고 브라우저에서 분석합니다.

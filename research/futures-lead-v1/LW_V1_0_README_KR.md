# LW 변동성 돌파 연구실 V1.0
- 래리 윌리엄스 계열의 변동폭 돌파 아이디어를 정량화한 자체 연구 규칙. 실전 전략 복제나 수익 보장 아님.
- 실행: `python lw_breakout_lab_V1_0.py`; 브라우저 http://127.0.0.1:8080. Python 3.10 이상, 표준 라이브러리만 사용. Render는 `--host 0.0.0.0`.
- 최근 완료 30일/60일, 한국 09시 기준. 오늘 시가 + 전일 (고가-저가) × K(0.3/0.5/0.7). 전일 거래대금 5억원 이상, 고정 1~10종목. 원화마켓만, 스테이블 제외.
- A: 첫 돌파 봉 목표가(갭은 시가), B: 첫 돌파 이후 종가 >= 목표가인 봉 다음 시가, C: 첫 돌파 후 6봉 이내 저가가 목표가 +0.3% 이내, 종가 목표가 위 양봉, 다음 봉 시가. 목표가 -0.2% 미만 종가면 C 취소. 동일 코인·일자·비교군 1회.
- DAY: 다음 09시 첫 봉 시가 매도. SCALP: 순익 +0.5%, 가격 -1%, 최대 12봉, 당일 종료 전 청산. 손절 우선, A 첫 봉 저가가 진입 전인지 불명인 경우 손절 우선으로 보수 가정. A의 시간은 해당 봉 시작 시각으로 기록. 수수료 편도 0.25%, 슬리피지 0. 체결 보장 없음.
- 각 비교군 세션 기준 하루 최대 4건, 동률은 코드 순; 제한 없는 결과도 표시. 투자금 배분·복리·동시 보유 자본은 별도 검증 필요. 합계 단순 합산, 실제 계좌 수익률 아님.
- 완료된 일봉 및 288개 5분봉, 다음 09시 봉 필요. 부족한 거래일 제외 및 진단 CSV 기록. 거래 없는 봉과 수집 실패 구별 불가. 완전 데이터만 선택한 표본의 편향 가능. API 제한 시 추가 조회 중단. 60일에 종목당 약 90회 요청, 실행은 오래 걸릴 수 있음. 고정 종목 표본은 전체 역사적 시장을 대표하지 않음.
- CSV: 거래, 18개 요약, 일자별 수집 진단. `python -m unittest -v test_lw_breakout_V1_0` 으로 20개 가상 테스트 실행. 실제 시장 성과는 아직 미확인.

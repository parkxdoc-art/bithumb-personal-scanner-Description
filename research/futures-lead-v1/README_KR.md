# 빗썸 × 바이낸스 선물 데이터 연구 V1.4.1

**연구 전용 · 자동 주문 없음 · 기존 V2/V3 미변경**

## 변경 사항

## V1.4.1 긴급 안전 수정 — Binance IP 제한 (2026-11-21)

- 실제 Render 연구 실행에서 바이낸스 API가 HTTP 418, 오류 코드 -1003을 반환했습니다. 표시된 **IP 차단 해제 예정 시각은 2026-11-24 05:54:58 KST**입니다.
- 차단 해제 전에는 Binance API를 **호출하지 않고**, 화면에 재시도 가능 시각을 표시하며 버튼 실행을 차단합니다. IP를 바꾸어 우회하는 방식은 사용하지 않습니다.
- 해제 후 모든 Binance 요청 사이 최소 **2초** 간격을 두고, 1개 작업자만 데이터를 수집합니다. HTTP 429가 오면 Retry-After(미제공 시 최소 5분) 동안 중단, 418이 오면 해당 차단 종료 시각까지 중단합니다.
- 기본 범위는 안전을 위해 **5개 코인 / 최근 6일**로 축소했습니다. **20개/13일 선택 기능은 유지**하며, IP 차단이 풀린 뒤에만 작은 범위부터 순차적으로 검증해야 합니다.
- G/N/X 신호, 수수료 0.5%, 고정·구조 손절/확인 진입 연구 로직은 V1.4와 동일합니다.
- 이전 13일·20종목 연구는 API 차단으로 수집 실패했으며, 이 수정만으로 실전 예측력을 입증한 것이 아닙니다.
- 테스트: API 요청 없는 오프라인 회귀 테스트 25개 통과.
- 기존 V2·V3 및 다른 Render 서비스의 코드/배포 설정은 변경하지 않습니다.


- 기존 G 후보 신호 조건과 N/X 내부 비교군은 그대로 유지. **이전 6일 CSV에 맞춘 매매 조건 조정 없음**.
- 기본 연구범위: 최근 **13일, 20개 코인** (기존 6일/10개 대비 확대). API 공통 상장 종목만 분석하며, 제외/실패 종목도 화면에 표시.
- 데이터 수집: 바이낸스 15분 OI·taker 매수/매도량, 빗썸 5분 OHLC(종가+저가), BTC 1시간 상승률.
- G 진입 후 **첫 5분 가격변화**와 약세군(가격 -0.3% 이하) vs 비약세군을 분리 표시. 이미 진입한 뒤 알 수 있는 **사후 진단**이지, 사전 필터가 아님.
- 같은 G 신호에서 손절 모델 2개 비교: **고정 가격 -1%** vs **직전 30분의 완료된 5분봉 최저 저가에 0.15% 버퍼**. 구조 손절폭 0.30~3.00%만 비교 가능으로 표시하고, 나머지는 제외 건수 공개. 비교 표는 **같은 신호에 적용한 고정·구조 손절 평균**을 나란히 제공.
- 별도 진입 연구: 기존 진입 후 첫 다음 5분봉이 기존 진입가보다 **상승 종가 마감**했을 때만, **그다음 5분봉 종가**에 가상 진입. 모든 확인 봉은 완료봉만 사용. **확인 대상 비율/건수**와 확인 대상 신호의 기존 진입 성적도 함께 표시.
- 13일/20개 종목은 최대 3개 병렬 수집으로 부하 완화. API 제한/종목 미지원/캔들 누락은 결측 및 오류로 표기.
- 버전 V1.4.1 화면·코드·CSV 일치. 오프라인 단위 회귀 테스트 및 /health 응답 확인.

## 연구상 고정된 설정

- G형: 가격 직전 1시간 -0.5~+0.3%, OI 증가 0.8% 이상, taker 매수/매도비 1.08 이상, BTC 1시간 비하락.
- G 신호 시각은 15분 구간 완료 시각. 진입은 바로 다음 빗썸 5분봉 **종가** 가정.
- 기존 기본 익절: **순수익 +0.5%**, 수수료 왕복 0.5% 가정이므로 1% 이상 총 가격 상승을 요구.
- 기본 고정 손절: 총 가격 -1%에 도달한 **완료된 5분봉 종가** 기준. 수수료 포함 순손익은 대략 -1.5% 이하.
- 가격·익절·손절 종가 시뮬레이션만 수행. 저가는 *사전 구조 손절의 위치 산정*에만 사용하며, 이후 저가 터치 즉시 체결한 것으로 취급하지 않음.
- 후속 60분 완료봉 수익/순서, 180분 종가 성과 및 CSV 출력 유지.

## 주요 한계 및 주의

- **실제 시장 13일/20종목 백테스트는 별도로 실행해야 함.** 자체 테스트 통과는 전략 성과를 뜻하지 않음.
- 5분 첫 약세 분류는 진입 후의 정보를 사용하므로, 이를 진입 전에 알고 있다고 가정하면 선행지표/성과가 부풀려짐.
- 확인 진입은 기존 G 신호 전체가 아닌 확인 가능한 일부 신호에서만 실행하므로, 커버리지와 평균을 함께 검토해야 함.
- 구조 손절은 최소 6개 완료봉 저가가 필요하며 손절폭 범위 바깥이면 **매매를 생략하는 가정**. 비교군 누락을 숨기지 말 것.
- 모두 5분봉 **종가** 시뮬레이션이며, 실제 저가 터치, 슬리피지, 갭, 호가 깊이, 주문체결, 수수료 차이, 시장충격은 반영되지 않음.
- 연구 대상 거래소 API는 가용성·호출량·지역 제한이 있을 수 있음. 누락 데이터를 임의 보간하지 않음.
- G와 N 비교는 완전한 무작위실험이 아니며, 사후 선택된 통계 비교군이다. 표본 확대로도 예측성이 입증되지 않을 수 있음.
